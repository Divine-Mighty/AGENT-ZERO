## Milestones this raise should be sized to reach

Rather than sizing the ask to an arbitrary runway length, size it to the Phase 1 exit criteria defined in [[Scaling Plan]]:

- [ ] Factory 01 8-stage line running at validated, repeatable throughput — illustrative target: **≥25 units/month sustained for 3 consecutive months**
- [ ] Robotics-line uptime validated at target % — illustrative target: **≥80% sustained over a full production quarter**
- [ ] NCC/AS-NZS certification achieved for the residential product
- [ ] First residential units sold — illustrative target: **≥25 units sold/deposited**
- [ ] First disaster-relief pilot deployment or agency contract secured
- [ ] Digital-twin platform live (beyond a static QR tag) for at least the first production cohort

## What this ask deliberately does not include

Consistent with the integrity constraint running through this vault: this note does not include a market-size-derived revenue projection, a comparable-company valuation benchmark, or a cited industry funding-round comparison, because none of that research was done. Any version of this note used in an actual raise needs those inputs sourced properly first — see the flags throughout [[Market Opportunity (Illustrative Model)]] and [[Unit Economics]].
